## Installation

Add the Argide widget to your site with a single script tag:

<Tabs>
  <Tab title="Script Tag">
    ```html
    <script
      src="https://dashboard.argide.ai/argide-b2b.iife.js"
      data-api-url="https://api.argide.ai"
      data-product-id="YOUR_PRODUCT_ID"
    ></script>
    ```
  </Tab>

  <Tab title="React SDK">
    ```bash
    npm install @argide/react-chat
    ```

    ```tsx
    import { ArgideWidget } from '@argide/react-chat';
    import '@argide/react-chat/styles.css';

    <ArgideWidget productId="YOUR_PRODUCT_ID" apiUrl="https://api.argide.ai" />
    ```
  </Tab>
</Tabs>

## Core Features

| Feature                 | What it does                                                          |
| ----------------------- | --------------------------------------------------------------------- |
| **Knowledge Base**      | Agent learns from your docs, website                    |
| **API Integration**     | Agent calls your API to take actions (check orders, cancel subscriptions) |
| **User Identification** | Agent knows the user's name — no backend needed                       |
| **Identity Verification** | Agent acts on the user's behalf against your API                    |
