View all conversations your agent has with users at [dashboard.argide.ai/dashboard/activity](https://dashboard.argide.ai/dashboard/activity).

## Layout

- **Left panel** — Conversation list with filters
- **Right panel** — Selected conversation details

## Filters

| Filter            | Options              |
| ----------------- | -------------------- |
| **Date range**    | Start/end date       |
| **Status**        | Success, Error       |
| **Message count** | Number of messages   |
| **Search**        | Text search          |

## Conversation Details

Each conversation in the list is labelled with the user's name, or "Anonymous visitor" if you haven't identified them. See [User Identification](/setup/user-identification) to pass the name.

### Chat Tab

Full conversation as users see it:

- User messages
- Agent responses
- Tool calls and results
- Timestamps

### Tool Calls

Tool calls appear inline with parameters and results:

```
🔧 Calling: getOrderStatus
   Parameters: {"orderId": "ORD-12345"}
✅ Result: {"status": "shipped"}
```

### Details Tab

| Field                  | Description                                              |
| ---------------------- | -------------------------------------------------------- |
| **Name**               | The user's name, if you passed one                       |
| **Email**              | The user's email, if you passed one                      |
| **User ID**            | Your own ID for the user                                 |
| **Custom attributes**  | Any extra attributes you sent — hidden when there are none |
| **Session ID**         | The browser session the conversation belongs to          |
| **Started**            | When the conversation began                              |

Token usage and cost have their own **Cost** tab.

The badge next to the user tells you where the identity came from:

| Badge          | Meaning                                                                     |
| -------------- | --------------------------------------------------------------------------- |
| **Anonymous**  | You never identified this user                                              |
| **Unverified** | Attributes came from `data-*` or `update` — taken on trust                  |
| **Verified**   | Confirmed by a JWT via [Identity Verification](/integration/identity-verification) |

### Traces Tab

Raw debugging data — useful for complex issues.

## Use Activity To

- **Identify gaps** — Questions agent can't answer → add to knowledge base
- **Spot issues** — Errors, tool failures
- **Track volume** — Conversation trends over time
